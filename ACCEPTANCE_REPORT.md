- Старый документ в базе (`Ð‘Ð¸Ð·Ð½ÐµÑ…docx`) исправлен на `Бизнес-обоснование_пилотной_системы_ПТО.docx` в БД, физический файл не переименовывался; повторный dry-run — 0 проблем.

- UI: viewer открывается внутри приложения, документ не скачивается; скачивание отдельной кнопкой.

## 4. Ограничения, зафиксированные честно

| Ограничение | Причина | Обход / план |
| --- | --- | --- |
| DOC/XLS не просматриваются встроенно в тестовой среде | LibreOffice не установлен | установить LibreOffice на VPS (инструкция) или скачать файл |
| Сложное форматирование DOCX (формулы, сноски, OLE, колонтитулы) не отображается | собственный безопасный конвертер поддерживает базовые элементы | предупреждение в окне просмотра; при необходимости — этап с LibreOffice-конвертацией в PDF |
| Формулы XLSX не вычисляются | используются сохранённые значения | вычисление формул не требуется для просмотра |
| Большие документы показываются частично | ограничения ресурсов сервера | лимиты указаны в отчёте |
| PDF-просмотр — встроенный движок браузера | без внешних CDN и тяжёлых библиотек | при требовании собственного интерфейса — локальный PDF.js отдельным этапом |
| XLSX-выгрузки отчётов | не входили в текущий этап | ROADMAP, этап 2 |
