## 2. Действие

1. Выполнен **dry-run** (`npm run report-filenames`), CSV-отчёт: `reports/filename-repair-dry-run.csv`.
2. Проверена однозначность: перекодировка `latin1 → utf8` даёт валидную строку без символов замены, кириллица корректна.
3. Выполнено **применение** (`npm run report-filenames -- --apply`) — изменены **только поля БД** `Оригинальное_имя` (документ ID 24, редакция ID 1).
4. Физические файлы **не переименовывались** — `uploads/1795062067581_51b55260df6986c7.docx` остаётся на месте.
5. Повторный dry-run: **0 искажённых имён**.

---

## 3. Результат

- В карточке документа и в блоке редакций отображается `Бизнес-обоснование_пилотной_системы_ПТО.docx`.
- Скачивание отдаёт это же имя (`Content-Disposition` + `filename*`).
- Просмотр DOCX работает (собственный конвертер).
- Новые загрузки сохраняются корректно (подтверждено автотестами `tests/filenames.test.js`: 5 имён с кириллицей, все этапы цепочки).

---

## 4. Как повторить

```bash
# только чтение и отчёт
npm run report-filenames

# применить исправления к БД (после проверки отчёта и резервной копии)
npm run report-filenames -- --apply
```

Физические файлы скрипт не изменяет ни в одном режиме.
