# USER_MANUAL_PTO — инструкция пользователя ПТО

Система: «База знаний и реестр ПТО» ООО «ИНФОТЕХ БАЛАКОВО» (внедрение — ООО «СтройМонтажГрупп»).
Адрес для пилота: `https://<домен>` (локально — `http://127.0.0.1:3001`).

---

## 1. Вход и начало работы

1. Откройте адрес системы в браузере (Chrome, Edge, Яндекс.Браузер или Firefox).
2. Введите **табельный номер** и **пароль**, нажмите «Войти».
3. После входа открывается **Панель ПТО**.

При первом входе смените пароль: кнопка **⚙** в правой части шапки → «Смена пароля». Требования: не короче 10 символов, буквы и цифры, не содержит табельный номер и название организации.

Если пароль забыт — обратитесь к администратору (он может сбросить пароль, не удаляя учётную запись).

---

## 2. Панель ПТО

На панели показаны **фактические** показатели по доступным вам объектам:

| Показатель | Что означает |
| --- | --- |
| Всего документов | документы в реестре |
| В работе | статусы «На проверке» и «На согласовании» |
| Утверждено | статус «Утверждён» |
| Просрочено | срок прошёл, документ не утверждён и не в архиве |
| Незакрытых замечаний | замечания в работе |
| Неполных комплектов | комплекты ИД, где не все позиции готовы |
| Комплектов готово | комплекты, где все позиции закрыты |
| Сдано в срок | доля утверждённых документов, актуализированных не позже срока |

Переключатель объекта меняет расчёт. Кнопка «Обновить» перечитывает данные.

Ниже — блок «Поиск по базе знаний и документам»: введите 2+ символа (название, шифр, текст) и нажмите «Найти». Результаты открываются в карточке; учитываются только доступные вам объекты.

## 3. Документы ПТО

### 3.1. Просмотр реестра

Раздел **«Документы ПТО»**:

- таблица: тип, документ (шифр и редакция), объект, раздел, статус, срок, ответственный;
- просроченные строки подсвечены, срок выделен красным;
- фильтры: тип, объект, статус, поиск, «только просроченные»;
- кнопка **«Выгрузить реестр»** формирует CSV по текущим фильтрам (открывается в Excel).

### 3.2. Создание документа

1. Нажмите **«Добавить документ»**.
2. Заполните тип (ИД, ППР, акт скрытых работ, журнал работ, входной контроль), объект, наименование, шифр, раздел проекта, статус, срок, ответственного, описание.
3. При необходимости приложите файл (PDF, DOC, DOCX, XLS, XLSX до 20 МБ).
4. Нажмите «Создать». Документ появится в реестре, запись о создании — в истории.

### 3.3. Карточка документа

Клик по названию открывает карточку:

- поля документа и ссылка на файл (открыть/скачать);
- **смена статуса**: выберите новый статус, при необходимости добавьте комментарий, «Применить»;
- **история**: кто, когда и что изменил (включая смену статуса и комментарии);
- **редакции**: версии 1, 2, … с файлами, автором и датой. Старые файлы не удаляются — можно скачать любую редакцию.

Кнопка «Редактировать» позволяет изменить поля. Если заменить файл или поставить галочку «Отметить как новую редакцию», версия увеличится, а прежний файл сохранится в истории редакций.

### 3.4. Импорт из CSV

Кнопка **«Импорт CSV»** → выберите файл.

Ожидаемые колонки (разделитель `;` или `,`):
`Тип;Наименование;Объект;Шифр;Раздел;Статус;Срок;Ответственный;Описание`

Тип можно указать кодом: `ИД`, `ППР`, `АОСР`, `ЖР`, `ВК`.

Порядок:

1. Система показывает предпросмотр: всего строк, готово, дубликаты, ошибки (по каждой строке — причина).
2. Если есть ошибки, кнопка «Импортировать» заблокирована — исправьте файл.
3. Дубликаты (то же название + шифр + объект) пропускаются.
4. Импорт выполняется одной транзакцией: при сбое не записывается ничего.

## 4. Комплектность ИД

Раздел **«Комплектность»** позволяет контролировать состав исполнительной документации.

1. **«Создать комплект»**: название, объект, ответственный, примечание.
2. Откройте комплект → **«Добавить требование»**: название позиции и тип документа (например, «Акты скрытых работ», «Исполнительные схемы ЭОМ»).
3. В строке требования выберите документ из списка и привяжите его.
4. Состояние позиции: «Готово» (есть документ в статусе «Утверждён»/«В архиве»), «В работе», «Отсутствует».
5. Кнопка **«Отчёт о недостающих (CSV)»** выгружает список незакрытых позиций — удобно передавать исполнителям.

Состав комплекта задаёте вы (или руководитель ПТО) — система не навязывает нормативный перечень. Типовые составы берутся из требований заказчика и регламентов проекта.

---

## 5. Замечания и предписания

Раздел **«Замечания»**.

1. **«Добавить замечание»**: объект, связанный документ, описание, ответственный, срок, статус. Номер присваивается автоматически (`ЗМ-ГГГГ-NNN`).
2. Ответственный получает уведомление в системе.
3. Карточка замечания: смена статуса с комментарием, комментарии, вложения (файлы), история изменений.
4. Фильтры: статус, объект, поиск, «только просроченные».

Статусы (настраиваются администратором): Новое, В работе, Устранено, Закрыто, Отклонено. Закрытие фиксирует дату.

---

## 6. Отчёты

Раздел **«Отчёты»**:

- выберите объект и период (или оставьте «все»), нажмите «Показать»;
- сводка: документов, в работе, утверждено, просрочено, срок ≤ 3 дней, открытые замечания, комплекты, доля сданных в срок;
- таблица распределения по статусам;
- выгрузки: **«Документы (CSV)»**, **«Замечания (CSV)»** — по текущему объекту.

---

## 7. Уведомления

Кнопка **🔔** в шапке показывает количество непрочитанных. Внутри — список: приближение срока, просрочка, смена статуса, назначение ответственным, новые замечания. Можно отметить одно или все как прочитанные.

Уведомления формируются внутри системы (без e-mail и мессенджеров). Планировщик проверяет сроки ежедневно и может быть запущен вручную администратором/инженером ПТО (API `/api/notifications/scan`).

---

## 8. Каталог знаний

Раздел **«Каталог знаний»** — инструкции, решения, нормативные материалы по видам работ:

- поиск по названию, тексту, ключевым словам;
- фильтр по виду работ;
- раскрытие статьи, открытие приложенного файла.

Наполняют каталог администратор и старший монтажник (в рамках их прав).

---

## 9. Права по ролям

| Роль | Возможности |
| --- | --- |
| Монтажник | просмотр каталога и документов своих объектов |
| Старший монтажник | каталог знаний (статьи, работы, виды работ), просмотр ПТО |
| Инженер ПТО | документы ПТО, комплекты, замечания, импорт, реестры по своим объектам |
| Администратор | всё, включая сотрудников, доступ к объектам, журнал действий |

Доступ к объектам назначает администратор (раздел «Сотрудники» → «Объекты»). Без назначенных объектов сотрудник не увидит документы этих объектов.

## 10. Частые вопросы

**Не вижу документ другого объекта.** Это нормально: доступ ограничен объектами, назначенными администратором.

**Файл не открывается.** Проверьте, что вы авторизованы; ссылка на файл требует входа. Если файл удалён с диска — обратитесь к администратору (в истории может быть старая редакция).

**Почему документ помечен «Требует OCR»?** Файл — скан без текстового слоя; полнотекстовый поиск по его содержимому не работает. Текст из PDF/DOCX/XLSX с текстовым слоем индексируется автоматически.

**Можно ли восстановить удалённый документ?** Через интерфейс — нет. Администратор может восстановить данные из резервной копии (см. `DEPLOYMENT_RU_VPS.md`).

**Как передать реестр заказчику?** «Документы ПТО» → «Выгрузить реестр» (CSV) или «Отчёты» → «Документы (CSV)». Форма отчёта — стандартная; требования заказчика к форме нужно согласовать отдельно.
